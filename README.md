# MyOperator Data Analyst Assignment

This repository contains my submission for the Data Analyst role assignment at MyOperator.

## 📊 Objective
Analyze the provided sales dataset and extract actionable insights to help improve decision-making.

## 🛠 Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Excel (for quick lookups)
- PowerPoint (to present insights)

## 📂 Repository Structure
- `dataset/`: Raw dataset provided.
- `notebooks/`: Jupyter notebook / Python script used for analysis.
- `outputs/`: Cleaned & summarized CSVs for trends, patterns, and correlation.
- `MyOperator_Sales_Analysis.pptx`: Final presentation report.

## 📌 Key Insights
- Peak sales hours are between X-Y.
- Product line Z contributes most revenue in Branch B.
- Strong correlation observed between Rating and Total Bill (r = 0.XX).
